04 | SYMMETRIC ENCRYPTION

One shared secret key

Symmetric encryption uses the same key for both encryption and decryption.

How it works

  1. Alice and Bob both know the shared secret key.
  2. Alice encrypts the message using the key.
  3. The encrypted message is sent to Bob.
  4. Bob uses the same key to decrypt it.

Advantages

  • Fast.
  • Efficient for large amounts of data.

Disadvantage

The secret key must be shared securely. If someone intercepts the key, they could decrypt the messages.

07 | CAESAR CIPHER

A simple way to encrypt letters

The Caesar Cipher is a simple way of doing encryption by shifting letters in the alphabet.

ABCDEFGHIJKLMNOPQRSTUVWXYZ

How it works

We use a key (a number) to shift every letter.

Example: key = 3. Each letter moves 3 places forward.

HELLO → KHOOR

For decryption, move each letter 3 places backwards.

KHOOR → HELLO

Why does it work?

  • The key tells us how many places to shift letters.
  • Without the correct key, the message looks like random letters.
  • With the correct key, we can get the original message back.

Real-world context

Modern encryption is much stronger and more complicated, but the basic idea is similar: encryption helps keep data private from people who should not see it.

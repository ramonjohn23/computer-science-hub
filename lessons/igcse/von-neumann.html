04 · REGISTER CHALLENGE

How does the CPU keep track?

Imagine the computer has been given this program:

12 + 8 = 20

1 LOAD 12   2 ADD 8   3 STORE 20

The CPU needs to remember where the next instruction is, where information is stored, what is being transferred, which instruction is being decoded and the calculation result.

PC · Program Counter

Stores the address of the next instruction to be fetched.

MAR · Memory Address Register

Stores the address in memory currently being accessed.

MDR · Memory Data Register

Stores data that has been read from memory or is about to be written to memory.

CIR · Current Instruction Register

Stores the current instruction being decoded and executed.

ACC · Accumulator

Stores data temporarily during calculations.

06 · SYSTEM BUSES

The roads inside the computer

Buses are communication pathways that allow the CPU, memory and I/O devices to communicate.

01

Address Bus · WHERE?

Carries the address of a memory location. The CPU uses it to identify where information is stored.

02

Data Bus · WHAT?

Carries the actual data and instructions between the CPU and memory. It is bidirectional.

03

Control Bus · WHAT SHOULD HAPPEN?

Carries control signals, for example READ FROM MEMORY and WRITE TO MEMORY.

Memory

08 · PERFORMANCE FACTORS

Four factors affect CPU performance

⚡

Internal clock / Clock speed

Number of clock cycles the CPU can perform per second.

🧠

Number of cores

Number of processing units inside the CPU. More cores can allow multiple tasks to run at the same time.

📦

Cache memory

Very fast memory close to the CPU. Reduces time waiting for frequently used data and instructions.

🚌

Bus width

Amount of data or address information transferred at once. Wider buses can transfer more information at a time.

CPU performance depends on more than just clock speed. CPU architecture also affects overall performance.

09 · CLOCK SPEED

What is clock speed?

Definition

Clock speed tells us how many clock cycles the CPU can perform each second.

It is measured in Hertz (Hz).

Example: 3.5 GHz

3.5 billion

3.5 billion clock cycles per second.

A higher clock speed can allow the CPU to process instructions more quickly, which can make the computer feel faster when performing CPU-dependent tasks.

11 · CPU CORES

What is a CPU core?

A core is an individual processing unit inside a CPU. Think of a CPU as a team of workers.

1

1-core CPU

One processing unit.

2

2-core CPU

Two processing units. The CPU can potentially work on multiple tasks at the same time.

4

4-core CPU

Four processing units. More cores can allow the CPU to handle multiple tasks simultaneously.

More cores can mean more tasks processed at the same time. However, more cores do not automatically mean a CPU is faster. Software must be able to make effective use of those cores.

13 · BUS WIDTH

Wider bus = more information at once

The width of the address bus and data bus can affect CPU performance.

Narrow road

Only a small amount of information can travel at once.

32-bit

A 32-bit data bus can transfer 32 bits at a time.

Wide road

More information can travel at once.

64-bit

A 64-bit data bus can transfer 64 bits at a time.

In general, wider buses can transfer more information at a time.

15 · OVERCLOCKING

Making your CPU run faster

Overclocking means increasing the CPU's clock speed above the speed it was designed to run at.

Normal speed

3.5 GHz
→

Overclock

4.0 GHz

The clock speed can be changed through the computer's BIOS settings.

Possible advantage

Higher speed can potentially allow more instructions to be processed per second.

Possible problems

  • Computer becomes unstable.
  • System instability or crashes.
  • Overheating because the CPU produces more heat.
  • Unreliable performance.

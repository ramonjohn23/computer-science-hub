01 · Number systems

Why do computers use binary?

Information must be converted into binary so that it can be processed by a computer.

Electronic switches

A computer contains millions of tiny switches that can be turned ON or OFF.

ON = 1   |   OFF = 0

Binary

Binary is a base 2 number system. It uses only the digits 0 and 1 to represent values.

Denary

Denary is a base 10 number system. It uses the digits 0 to 9.

Hexadecimal

Hexadecimal is a base 16 number system. It uses 0–9 and A–F.

Number systemBaseDigits used
Binary20, 1
Denary100–9
Hexadecimal160–9, A–F

02 · Binary addition

Rules for binary addition

Binary addition uses only 0 and 1. When the sum reaches 2, a carry is produced.

Binary additionCarrySum
0 + 000
0 + 101
1 + 001
1 + 110

When adding three binary digits

Binary additionCarrySum
0 + 0 + 000
0 + 1 + 110
1 + 0 + 110
1 + 1 + 111
The same process is followed as denary addition, but binary uses only two digits. Carrying occurs when the sum reaches 2 instead of 10.

Worked example

Add 00100111 + 01001010.

00100111
+ 01001010

01110001

Carry values are passed to the next column on the left when a column adds to 2 or more.

Answer: 01110001

Check using denary

01001010₂ = 74

39 + 74 = 113

01110001₂ = 113, so the result is correct.

03 · Two’s complement

Representing positive and negative integers

Two’s complement allows a computer to represent both positive and negative integers.

8-bit place values

−128   64   32   16   8   4   2   1

In two’s complement, the left-most bit has a value of −128. All other place values remain the same.

Range

−128 to +127

Smallest: 10000000 = −128

Largest: 01111111 = +127

Sign bit

Left-most bit 0: positive or zero.

Left-most bit 1: negative.

Example: 11001111 represents −49 because −128 + 64 + 8 + 4 + 2 + 1 = −49.
03 · Two’s complement

Convert a positive denary number

Because the number is positive, place 0 in the −128 column.
Select the remaining place values that add up to the denary number.
Write the eight bits in order.

Example: +38

38 = 32 + 4 + 2

0 0 1 0 0 1 1 0

+38 = 00100110

Convert positive binary to denary

01101110 has a 0 in the left-most bit. Add the positive place values:

64 + 32 + 8 + 4 + 2 = 110

01101110 = +110

03 · Two’s complement

Convert a negative denary number

There are two methods shown in the lesson.

Method 1 · Use the negative place value

For −67, start with −128. The remaining value needed is 61 (32 + 16 + 8 + 4 + 1).

−128 + 32 + 16 + 8 + 4 + 1 = −67
10111101

Method 2 · Invert and add 1

Write the positive value +67 in 8-bit binary: 01000011.
Invert every bit: 10111100.
Add 1: 10111101.

−67 = 10111101

04 · Overflow

Overflow in an 8-bit register

An 8-bit unsigned binary number can store a maximum denary value of 255 (2⁸ − 1).

8-bit register

00000000 to 11111111

Denary range: 0 to 255.

Overflow

If an addition generates a ninth bit, the result has exceeded the value that can be stored in 8 bits. This is called an overflow error.

Example from the lesson

110 + 222 = 332. The 8-bit result shown is 01001100, which represents 76. The ninth bit has been generated and the correct total cannot be represented in 8 bits.

110 + 222 = 332   →   overflow

04 · Logical binary shift

Logical left and right shifts

A logical shift moves the bits in a binary number to the left or to the right.

Left shift

Shift left = × 2

Each left shift multiplies a positive binary integer by 2.

Right shift

Shift right = ÷ 2

Each right shift divides a positive binary integer by 2.

As bits are shifted, empty positions are replaced with 0. Bits that move beyond the register are lost.

Example

01110000 is 112 in denary. Shifting it five places left in an 8-bit register eventually produces 00000000 because bits are shifted out of the register.

01110000 → 00000000

The fixed 8-bit register cannot retain all the bits after this many shifts.

Lesson summary

What should you remember?

Number systems

Binary is base 2, denary is base 10 and hexadecimal is base 16. Each hexadecimal digit represents four binary bits.

Binary addition

1 + 1 gives a sum of 0 and a carry of 1.

Two’s complement

The left-most bit has a value of −128 in an 8-bit representation. The range is −128 to +127.

Overflow

An 8-bit unsigned register cannot store a value greater than 255.

Logical shifts

Left shift multiplies by 2 per place; right shift divides by 2 per place. Empty positions are filled with zeros.

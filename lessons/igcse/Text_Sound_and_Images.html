Lesson objectives

How is information represented?

Computers cannot store letters, pictures or sounds directly in the way humans understand them. They convert this information into binary data so it can be processed and stored.

Text

Characters are assigned numeric codes using character encoding systems such as ASCII and Unicode.

Sound

Analogue sound is sampled at regular intervals. Each sample is stored as a binary value.

Images

Bitmap images are represented by pixels, with binary values describing their colours.

By the end of this lesson you should be able to: explain ASCII and Unicode; describe sampling, sample rate and sample resolution; compare bitmap and vector images; explain pixels, colour depth and image resolution.
Part 1

Text representation

Each character (letter, number or symbol) is represented by a numeric code. The computer stores that code in binary.

ASCII

  • ASCII means American Standard Code for Information Interchange.
  • Standard ASCII uses 7 bits, giving 128 possible codes (0–127 denary).
  • It represents common English letters, digits and keyboard symbols.
  • Extended ASCII uses 8-bit codes (0–255), adding another 128 code values.
Example: uppercase A has decimal code 65 and 8-bit binary representation 01000001.

Unicode

ASCII cannot represent characters from every writing system. Unicode was developed to provide a universal character set that can represent characters from languages around the world, including symbols and emoji.

  • The first 128 characters overlap with standard ASCII.
  • Unicode supports several thousand characters, including characters from many languages and writing systems.
  • The Unicode Consortium was set up in 1991.

Five goals of Unicode in the presentation

  1. Create a universal standard covering all languages and writing systems.
  2. Produce a more efficient coding system than ASCII.
  3. Use uniform encoding, with characters encoded using 16-bit or 32-bit codes.
  4. Make encoding unambiguous: each 16-bit or 32-bit value represents the same character.
  5. Reserve part of the code for private use so users can assign codes to their own characters and symbols.

Part 2

Sound representation

Sound in the real world is analogue: it consists of continuous waves that vary over time. A computer processes digital data, so analogue sound must be converted into binary.

How sampling works

  1. A microphone detects sound vibrations and converts them into an electrical signal.
  2. An analogue-to-digital converter (ADC) takes measurements of the wave at regular time intervals.
  3. Each measurement is converted into a binary value called a sample.
  4. The samples are stored and can later be converted back into a signal for playback.
Sampling is taking measurements of an analogue sound wave at regular time intervals. More frequent samples can represent changes in the wave more accurately.

Sample rate

The sample rate is the number of samples taken per second. It is measured in hertz (Hz). 1 Hz = 1 sample per second. A higher sample rate generally captures more detail but increases file size.

Sample resolution (bit depth)

Sample resolution is the number of bits used to store each sample. More bits allow more possible amplitude values, giving a more accurate representation of the sound wave.

Higher sample rate

More samples each second; can represent changes over time more closely; larger file size.

Higher sample resolution

More possible values for each sample; greater amplitude detail; larger file size.

Part 3

Image representation

Bitmap (raster) images

A bitmap image is made up of tiny squares called pixels (picture elements). Pixels form a two-dimensional grid, and each pixel is represented using binary data that identifies its colour.

Vector images

Vector images are made from mathematical descriptions of shapes, lines and curves rather than a grid of pixels. They can usually be enlarged without becoming pixelated.

Bitmap imageVector image

Colour depth

Colour depth is the number of bits used to represent the colour of each pixel. The number of possible colours is calculated using:

Number of possible colours = 2colour depth

Image resolution

Image resolution is the number of pixels that make up an image. For example, an image with a resolution of 4096 × 3072 contains 12,582,912 pixels.

Higher resolution means more pixels and usually more detail. Lower resolution images contain fewer pixels and may look fuzzy or pixelated when enlarged.

Image size estimator

For an uncompressed bitmap, a simplified estimate is:

File size in bits = width × height × colour depth
11,520,000 bits · 1.44 MB (decimal)

This is a simplified uncompressed estimate. Real file sizes can differ because of headers, metadata, file formats and compression.

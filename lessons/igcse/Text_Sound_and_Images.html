03 | Character Encoding

What is ASCII?

ASCII stands for American Standard Code for Information Interchange.

7-bit character set

ASCII was set up in 1963 for use in communication systems and computer systems.

It assigns a numerical value to letters, numbers and symbols so computers can represent text.

Standard ASCII uses 7 bits.

0 to 127 (denary)

00 to 7F (hexadecimal)

03 | Character Encoding

Extended ASCII

8-bit codes

Extended ASCII uses 8-bit codes.

This provides 256 possible code values, from 0 to 255 in denary, or 00 to FF in hexadecimal.

Why was it introduced?

It provides another 128 code values to allow additional characters, including characters used in some non-English alphabets and graphical characters.

03 | Character Encoding

Disadvantage of ASCII

Limited character support

The main disadvantage of ASCII is that it does not represent characters in many non-Western languages, for example Chinese characters.

Different methods of coding were developed to address this limitation.

Solution: Unicode

Unicode provides a common character encoding standard that supports characters from languages and writing systems around the world.

03 | Character Encoding

What is Unicode?

Universal character set

Unicode can represent characters from languages and writing systems around the world.

  • Supports many operating systems, search engines and internet browsers.
  • The first 128 characters overlap with standard ASCII.
  • Can support a very large range of characters and symbols.
  • The Unicode Consortium was set up in 1991.
03 | Character Encoding

Unicode encoding

Unicode was designed to create a universal and consistent standard for written characters.

Universal

Support languages and writing systems around the world.

Consistent

Use a common standard for representing characters.

Unambiguous

Character code values identify the same characters consistently.

Flexible

Supports a wide range of characters and symbols.

Unicode can use encoding formats such as UTF-8, UTF-16 and UTF-32. The number of bytes used depends on the encoding format and character.

05 | Sound Representation

What is sound?

Sound waves are vibrations in the air. The human ear senses these vibrations and interprets them as sound.

Each sound wave has:

Frequency

Number of wave cycles per second. Measured in hertz (Hz).

Wavelength

Distance between corresponding points on consecutive waves.

Amplitude

Specifies the loudness of the sound.

Low frequency

05 | Sound Representation

Analogue and digital sound

Analogue sound

Sound in the real world is analogue. It is represented by continuous waves that vary over time.

Continuous

Digital sound

Computers work digitally and can only process binary data.

0 and 1

How is sound converted?

A microphone detects sound vibrations and converts them into an electrical signal. An analogue-to-digital converter (ADC) converts the signal into digital values.

05 | Sound Representation

What is sampling?

Sampling

Sound is recorded at set time intervals. This process is known as sampling.

  • The computer takes measurements of the sound wave at regular time intervals.
  • Each measurement is converted into a binary value.
  • The computer stores these values to edit and play back the sound digitally.

Analogue-to-digital converter (ADC)

The ADC converts the analogue signal into digital data.

05 | Sound Representation

Sample rate

Samples per second

Sample rate is the number of sound samples taken every second.

Sample rate is measured in hertz (Hz).

Remember

1 hertz = 1 sample per second.

44.1 kHz = 44,100 samples per second.

If the intervals between samples are closer together, more samples are taken and the sound can be represented more accurately.

05 | Sound Representation

Sample resolution

Bits per sample

Sample resolution is the number of bits used to store each sound sample.

A higher sample resolution allows more possible amplitude values to be represented.

Example: 16-bit resolution

Each sample is stored using 16 bits.

This allows a large range of sound amplitudes to be represented, creating more accurate and detailed sound recordings.

05 | Sound Representation

Benefits and drawbacks

Higher sampling rate

More samples are taken each second.

Can capture changes in the sound wave more accurately.

Increases the amount of data stored.

Higher sample resolution

More bits are used for each sample.

Allows more possible amplitude values.

Increases the amount of data stored.

Key point

Higher sample rate and resolution generally produce a more accurate digital recording, but increase file size.

06 | Image Representation

Bitmap images and pixels

A bitmap image is made up of many small squares called pixels (picture elements).

An image is stored as a two-dimensional matrix of pixels.

Each pixel is stored as a binary number, allowing the computer to represent and process the image.

Example of a simple pixel grid.

06 | Image Representation

Colour depth

Colour depth is the number of bits used to represent the colour of each pixel.

1 bit per pixel

2 colours

0 = black

1 = white

2 bits per pixel

4 colours

00, 01, 10, 11

2² = 4 possible values.

3 bits per pixel

8 colours

000 to 111

2³ = 8 possible values.

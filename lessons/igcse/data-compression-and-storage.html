02 | STORAGE UNITS

Which is bigger?

  1. 1 Byte or 8 bits?
  2. 1 KiB or 1,024 bytes?
  3. 1 MiB or 1,024 KiB?
  4. 1 GiB or 1,024 MiB?

They are all equal!

Each pair represents the same amount of data in different units.

02 | STORAGE UNITS

The conversion rule

Moving to a larger unit

KiB → MiB → GiB → TiB

÷ 1,024

Divide by 1,024.

Moving to a smaller unit

TiB → GiB → MiB → KiB

× 1,024

Multiply by 1,024.

Important

Use 1,024 for storage conversions, NOT 1,000.

03 | IMAGE FILE SIZE

Image file size challenge

Formula

Width × height × colour depth

Width and height are measured in pixels. Colour depth is measured in bits per pixel.

Bits ÷ 8 = Bytes
03 | WORKED EXAMPLE

Calculate an image file size

Resolution: 800 × 600 pixels. Colour depth: 24 bits.

Step 1

800 × 600 = 480,000 pixels

Step 2

480,000 × 24 = 11,520,000 bits

Step 3

11,520,000 ÷ 8
1,440,000 bytes

04 | SOUND FILE SIZE

Sound file size

Formula

Sample rate × sample resolution × length

For stereo, multiply by the number of channels.

Mono = 1 channel | Stereo = 2 channels

Bits ÷ 8 = Bytes
04 | WORKED EXAMPLE

Calculate a sound file size

Sample rate = 44,000 Hz
Sample resolution = 16 bits
Length = 10 seconds
Stereo = 2 channels

44,000 × 16 × 10 × 2 = 14,080,000 bits
14,080,000 ÷ 8
1,760,000 bytes

05 | DATA COMPRESSION

Why do we compress files?

Imagine your phone has only 100 MB of storage left. Would you rather have a 10 MB photo or a 2 MB photo?

Compression = Smaller File

💾 Less storage

Files take up less space.

🌐 Less bandwidth

Less data is needed to transfer files.

⚡ Faster transmission

Smaller files can be transferred more quickly.

05 | COMPRESSION

Lossy vs Lossless

Lossy Compression

Data removed

Permanently removes some data. Usually creates a much smaller file, but quality is lost.

Examples

Lower image resolution, lower colour depth, lower sound sample rate or resolution.

Advantage

Much smaller file.

Disadvantage

Quality is lost.

Lossless Compression

Data preserved

Reduces file size without permanently removing data. The original can be reconstructed.

Examples

Run-Length Encoding, ZIP and PNG.

Advantage

No permanent quality loss.

Disadvantage

Usually less reduction than lossy compression.

06 | RUN-LENGTH ENCODING

What is RLE?

Run-Length Encoding

RLE is a type of lossless compression. It looks for repeated identical elements next to each other.

Instead of storing every element separately, it stores:

Number of repetitions + Value

RLE works best with long sequences of repeated data.

06 | RLE WORKED EXAMPLE

How does RLE work?

Original data:

AAAABBBCCDAA

Compressed data:

4A3B2C1D2A
CodeMeaning
4AFour A's
3BThree B's
2CTwo C's
1DOne D
2ATwo A's

When does RLE work best?

With long sequences of repeated data. If there are few repeated values, RLE may not reduce file size.

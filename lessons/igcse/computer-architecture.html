02 | HOW EARLY COMPUTERS WORKED

Early computers

  • Could not store programs in memory.
  • Could not store data for later use.
  • Required considerable human intervention.
  • Had to be given instructions while operating.

03 | THE STORED-PROGRAM COMPUTER

John von Neumann's key idea

In the mid-1940s, John von Neumann developed the concept of the stored-program computer.

Programs AND data can be stored in computer memory.

This was a major change.

Before

Human → Instructions → Computer

Instructions had to be entered manually.

Von Neumann

Program + Data → Memory → CPU

The computer can retrieve instructions from memory and execute them.

04 | CPU TERMINOLOGY

CPU = Processor = Microprocessor?

A CPU is very often implemented as an integrated circuit on a single microchip.

Integrated circuit (IC)

Many electronic components working together inside one tiny chip.

Imagine a city

Houses represent individual electronic components.

Roads represent connections between components.

The city represents the integrated circuit.

A tiny piece of land represents the microchip.

Think of the result

Many components are combined into one compact chip that performs the CPU's processing work.

05 | INSIDE THE CPU

Three main components

1

Control Unit (CU)

Controls and coordinates the activities of the CPU.

Think: CU = The Manager. It tells the other parts of the CPU what needs to happen.
2

Arithmetic and Logic Unit (ALU)

Performs arithmetic and logical operations.

Arithmetic: addition, subtraction, multiplication and division.

Logical: AND, OR, NOT and comparisons such as less than, greater than and equal to.

Think: ALU = The Calculator.
3

Registers

Small, very fast storage locations inside the CPU.

They temporarily hold data, instructions, addresses and intermediate results.

Think: Registers = CPU's scratch paper.

05 | THE BUSES

Highways of the CPU

Buses are pathways that carry information between the CPU, memory and I/O devices.

Data bus

Carries data between the CPU, memory and I/O devices.

DATA

Address bus

Carries addresses to memory and I/O (mainly from the CPU).

ADDRESS

Control bus

Carries control signals, such as read, write and interrupt.

CONTROL

Remember: Address bus = where; Data bus = what; Control bus = what action should happen.

06 | SYSTEM CLOCK

The computer's traffic controller

The system clock produces regular timing signals. It tells the CPU and other components when to perform each operation.

Keeps everything in sync

Coordinates when components send, receive or process information.

Without the clock

Different parts of the computer would not know when to send, receive or process information, which could cause the system to malfunction.

Timing signals

▁▔▁▔▁▔▁▔▁▔

The system clock keeps the CPU, RAM, I/O devices and other components working together in the correct timing.

07 | IMMEDIATE ACCESS STORE

RAM – the computer's working desk

RAM temporarily stores the programs and data currently being used by the CPU. The CPU moves the programs and data it needs from backing storage into RAM.

RAM = working desk

Holds the programs and data currently being used.

Hard drive / SSD = filing cabinet

Backing storage keeps programs and data for later use.

Backing store
Programs + data
→
RAM
Immediate Access Store
→
CPU
Processes data

How it works

  1. Programs and data are stored in backing storage.
  2. The CPU moves the required programs and data into RAM.
  3. The CPU accesses the data and executes the instructions.
Key point: RAM is much faster to read from and write to than backing storage, so keeping important data in RAM speeds up the computer.
